## Proposed short description

## Proposed full description

Seed lets you describe an idea to an AI coding agent and build a local web app on
your Android device. Its bundled Linux/Python runtime runs the generated app
locally, with a built-in app view, chat and terminal.

Choose a supported AI provider and configure your own credentials. AI features
require connectivity and send prompts and relevant task context to that provider.
Provider accounts, model availability and charges depend on the provider. Seed
does not promise free or offline AI generation.

Generated pages can request supported camera, foreground location and sensor
capabilities through explicit native consent. Permissions remain under your
control. Settings include runtime restart/recovery and Restore for replacing
damaged bundled runtime files within documented preservation limits.

This is an experimental beta for supported ARM64 devices. Agents and generated
Python have unrestricted authority within Seed's private runtime and can damage
files or expose credentials. Use noncritical data and test credentials. Restore
is not a backup and cannot recover data already deleted or undo disclosure.
Durable chat/history and broad device acceptance are incomplete.
